PURPOSE
Use this branch for isolated renderer/performance experiments described in
Arch/ARCHITECTURE.txt. The dev branch is not the experiment branch.

BASELINE DECISION
- Minecraft target: 26.2 only. Do not port to 26.3 unless explicitly requested.
- Source baseline: upstream Sodium mc26.2-0.9.2, chosen to avoid 26.3 renderer/API changes.
- Loader artifacts: Fabric and NeoForge; verify both build and launch.
- Build config uses Fabric Loader 0.19.3, Fabric API 0.161.0+26.2, and NeoForge 26.2.0.88.
- Language: Java. No JNI/Rust native renderer in this project.
- Branding and Arch documentation are layered onto the 26.2 source baseline.

EXPERIMENT ORDER
1. Thread contention / worker sizing on low-core CPUs.
2. Rebuild scheduling under frame-time pressure.
3. Meshing allocation pressure.
4. Memory profile, then other renderer targets guided by measurements.

WORKING RULES
1. One experiment per commit or small series of commits.
2. Measure before and after using the same world, route, settings, warm-up, and sample length.
3. Track average and p95/p99 frame times, chunk-loading stutter, memory, and GC where practical.
4. Keep risky behavior behind a configuration toggle where feasible.
5. Preserve upstream license notices and third-party attribution.
6. CI success proves compilation/packaging only, not in-game correctness or a performance win.
